## About
A very proyect specific code for cleansing the posting.csv. We are supposed make use of raw data to make a dashboard, star schema and make a PoweBI presentation at the end. 

## Features
- No GUI
- Terminal code
 
## Requirements
To run this project locally, you'll need the following:  
- **Python** (lastest LTS version recommended) - [Download here](https://www.python.org/downloads)  
- **Pandas** (Python Library)   
- **Numpy** (Python Library)  
- **Git** for version control - [Download here](https://git-scm.com/downloads)  
- A code editor (e.g [Visual Studio Code](https://code.visualstudio.com))  
- A terminal or command prompt  
- Draw.io or similar tool for star schema diagram creation  
- Power BI Desktop to visualize data and create dashboards  

### Optional
- Jupyter Notebook for interactive Python exploration 
- GitHub account for remote repository and collaboration  
This project has been testes on:  
- **Operating System:** Windows 11
